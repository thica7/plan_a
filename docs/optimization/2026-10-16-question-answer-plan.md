# 问题级回答与证据匹配实施计划

> 用户已确认依次实施覆盖假阳性、问题级语义检索、日期例外、缺报价答复，并复测 Miro / Basecamp / GitBook。本计划落实该授权，沿用当前隔离 worktree，不重复申请确认。使用 systematic-debugging、brainstorming、writing-plans、TDD 与 subagent-driven-development；独立模块并行使用 dispatching-parallel-agents。既有文档目录为 docs/optimization。

**目标**：报告对具体问题给出可核验的结论或明确的资料不足/澄清答复，不能用相关但对象不同的观察标记已回答。

**架构选择**：单纯增加审核提示词成本低，但上一轮已证明仍会误判；全量重构为自由规划问答成本和风险较高。本轮保留现有来源准入、快照、产物依赖与预算，增加问题级结论/片段合同、已有本机模型的有界混合选证以及通用时间例外保护。覆盖结论、取证结果与事实支持分别保存，未知关系保守处理。

**技术**：Python / Pydantic、现有本地 E5/BGE provider、既有受保护 Writer 和 DeepSeek 接口。生产改动不得依赖评测金标或产品名特判。

## 1. 覆盖假阳性与逐问结论（root）

文件：`backend/packages/agents/writer/answer_coverage.py`、新问题/回答校验辅助模块、`backend/packages/research/evidence/answer_coverage_models.py`、`backend/packages/agents/writer/dimension_writer.py`、QA 与对应测试。

- [ ] 从历史真实产物复现：folder 规则不能回答 private message；日期例外仅存在引用上下文不能被算作正文完整；reason 不是答案正文。
- [ ] RED：相关主张 ID 合法但对象不符、没有实际结论、片段不在主张中、角色/范围错误、重复或未知问题均拒绝 answered；正确的同对象原子规则及条件推断通过。
- [ ] 覆盖响应增加可显示的逐问结论、结论类型和对已支持主张的文字片段绑定。服务器验证结构、原始片段、已发表来源范围与可识别对象；未知不得强判完整。请求条件仍不能进入事实库。
- [ ] 覆盖/原文变化后最终 QA 重放同一规则，人工改稿与 force pass 不能绕过引用或覆盖保护。
- [ ] 局部报告展示实际答案与待澄清/不足原因，避免把相关资料列表当成已回答，也不复制泛用机会模板。

## 2. 问题级语义选证（独立子任务）

文件：新 `backend/packages/agents/writer/question_retrieval.py`、必要 `evidence_context.py` 可选 fact_ids 输入、专用测试；root 负责 Writer await 调用的集成。

- [ ] 匿名 RED：中文问题对英文事实跨语言词法零命中；对象近似但不一致；别产品/项目/过期或未支持资料不能借用；故障不能伪称语义模式成功。
- [ ] 在当前准入快照内使用现有本机 embedding，与词法排名融合；可选本机精排。仅复用已冻结本地权重，不调用外部 embedding，不以 hash 降级充当语义成功。
- [ ] 模型计算离开事件循环；有界候选数、每问和总数配额、完整原文不截断送 Writer，选证诊断包含模型版本、降级和选中 ID。原有消费记录保存实际 fact_ids，重放不重新排名。
- [ ] 相似度只用于选择，不是事实证明；记录选证容量不足，不把未选到等同于没有来源。
- [ ] 本机真实权重离线比较旧词法/新混合，参考答案不进入选证或任何 Agent prompt。

## 3. 日期例外及非操作条件（独立子任务）

- [ ] 匿名 RED：同角色一般权限否定存在“账号创建时间早于某日”的例外时，无条件否定拒绝；完整限定和澄清路径通过。
- [ ] 时间条件来自原始证据而非请求日期/核验日期；不串其他角色、对象或无关段落；不依赖特定产品、角色名或固定日期。
- [ ] 对无法证明作用域的关系保留未核实，不能靠规则通过声称一般语义证明。
