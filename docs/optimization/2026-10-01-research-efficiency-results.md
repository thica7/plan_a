# 调研效率优化验收记录

本阶段按已批准设计实施。以下记录区分真实官网抓取、真实模型、离线回归和未验收部分；完整联网流程按用户选择保留为未验收。

## 真实模型与预算

- 使用用户授权的本地凭据，`.env` 被 Git 忽略且文件权限为 `0600`，未写入源码、报告或浏览器。
- 官方 `/models` 返回 HTTP 200，配置使用 `deepseek-flash`。OpenAI 兼容入口为 `https://api.deepseek.com`，关闭 thinking。
- 最小 JSON 请求：输入 81 / 输出 39 / 合计 120 Token，模型将缺少官方证据的“iphone duo”标为需要确认，没有编造价格和规格。
- 任务预算同时限制调用、修复、Token 和美元估算。请求前持久化预留；响应按真实 usage 结算。中断且没有 usage 的请求保守收费；恢复不重置预算。
- 缓存命中与未命中分别计量，重试和截断返回同样计费。保守估算采用 DeepSeek Flash 官方高峰 USD 单价，并非账户账单。

参考：[官方模型与价格](https://api-docs.deepseek.com/quick_start/pricing)、[官方缓存说明](https://api-docs.deepseek.com/guides/kv_cache/)。缓存属于供应商尽力提供的能力，本阶段没有承诺固定节省比例。

**边界**：固定官源冒烟没有运行自动竞品发现、完整分析图或最终发布审查。初稿仍需要核对比较结论与个别截取不完整的字段；不能仅凭写作成功证明事实准确。当前缺少联网搜索凭据，完整自动检索与发现竞品尚未验收，真模型端到端重做也未运行；重做验收由离线运行器及路由回归覆盖。用户已选择本阶段先完成优化与测试，并保留这些未验收记录。

## 历史复用

历史复用先接入少量相关报告的原始出处，校验工作区、产品、市场和版本。所有候选链接都要求当前采集与证据准入；旧声明与旧引用不成为本次证据。最多 3 份报告、6 条背景事实、每采集分支 2 条链接；价格与版本使用 7 天边界，其他事实使用 30 天边界，全部链接仍要求重新采集。未审查、过期或来源明确未知的资料只提供待核验链接。

测试覆盖过期价格、来源缺失、模拟来源、服务重启恢复和错误产品页面。首次规格审查的 3 项缺口已在 `eceab1f` 修复：极简完整分支的可选社区搜索、共同竞品掩盖另一产品的版本冲突，以及单条证据显式未知模式。

质量审查发现的 3 项实际缺口已在 `391c193` 修复：重定向或重复内容按一个来源计量，覆盖不足仍搜索；可选历史读取异常保留只读 journal 回退，新任务正常持久化；旧日期只保存在历史关联字段，不覆盖当前抓取日期。独立规格复核 95 项通过，质量复审 54 项通过，无剩余阻断。

极简任务有历史出处且当前覆盖和准入均达标时，可跳过可选社区搜索。适中、详细和用户声音维度仍保留社区调研；这些模式省的是初始发现搜索，并非整个任务没有搜索调用。失败链接、错误产品、覆盖不足与关闭自动修复的任务仍保留常规搜索回退。

最终跨流程审查还发现：预检正确补抓独立来源，但最终 RawSource 列表只按 URL 排重，两个相同内容的历史页面会占满名额。`681b414`、`30f30a2` 已修复最终选择器：同一竞品和维度内，先按规范 URL 及原始捕获哈希去重，再占来源名额；当前日期及历史关联保留。原始捕获哈希单独记录，摘要备用哈希及缺乏捕获证明的旧记录不参与内容去重，避免错误丢弃不同页面。规格复审 13 项定点、176 项相关测试通过；最终质量复审 106 项通过，实际适配器复现为搜索 1 次、抓取 3 页，最终保留 2 份独立内容，包括补抓页面。无剩余审查阻断。

导出脚本及合成分组样例已提交，最后安全修复为 `ebfb044`。SQLite 输入只读，禁止输出覆盖源主库及 WAL、SHM、journal 文件，包括软链接和硬链接别名。按明确真实模式、工作区和关联反馈过滤；输出动作、有限摘要、耗时、用量与成本。完整文本先脱敏再生成摘要，覆盖中文紧邻敏感值及编码、转义凭据；明文及编码赋值在原始参数边界内完整处理，空白和参数值中的 `?`、`;` 不拆开凭据值，避免泄漏后缀。包含凭据的整个参数片段可保守省略，包括其中的 URL 前缀；`&` 后的公开参数保留。缺少完整原文且旧预览已截断或存在敏感残片时，明确省略原因。模拟调查和社区动作过滤，真实动作保留。
