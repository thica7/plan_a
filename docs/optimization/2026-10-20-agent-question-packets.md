# 逐题证据包、原子回答与四产品复验

## 改动范围

Analyst、Comparator、Reflector、Writer 通过共享入口，从当前准入快照按产品、维度和问题选择证据。问题、配置与快照身份绑定到消费凭据；分别记录准备选中、视图保留及模型实际收到的原文。候选事实 ID 存在不代表原文已发送，发送成功也不代表答案正确。

Reflector 区分局部上下文省略、无合格资料、词法零召回与无法核实派送。已知核心规则或例外遗漏仍保留缺口；未知、真实矛盾及比较要求继续审核。Planner、Survey 和封存前的 Collector 不伪装消费未来证据包。

当前显式功能问题使用逐题写作计划：模型一次返回事实原子，服务器逐条审核完整主张及引用。其他无问题维度保留既有路径。八条主张、单范围 14000 bytes 及各阶段预算均未扩大。

产品事实与澄清分开。`binding_version=3` 的事实原文必须完整发表并绑定，澄清由服务器按有限缺项生成，不能提供未知输入或创造产品规则。首版字段涵盖操作、数据归属、保留副本和访问路径；未覆盖的澄清类型保持未核实。`reason` 仅说明实际选择、状态及缺项，不能夹带未发表结论。旧 v2 记录继续按原合同读取。

最终 QA 重放 Writer 的视图、收据和已记录的直接上游凭据。Writer 从实际派送的最终 compact 保存使用关系，省略的上游不被误算为已使用；读取校验不改变运行状态。没有新增传递依赖图。

## 工程验证

最终后端 **6308 通过、1 跳过**（212 条既有弃用警告）；变更范围 33 个 Python 文件的 Ruff E9/F、空白检查、后端与生成 OpenAPI 一致性、旧 TypeScript 赋值及前端构建通过。API 有意改变 `ReportAnswerCoverage`、`ReportDimensionAudit` 两个 schema，端点及鉴权结构未变。全后端另有四处既有 F401，不作为本轮已清理内容。

新增不足答复使用 `partial + insufficient + unknown`；历史记录可读取，重新做当前 QA 时旧 `answered + insufficient` 不再视为满足不足状态要求。旧 v2 来源与引用选择合同保留，新功能问题以 v3 重放。

实现前保留失败用例，经过规格、独立质量及累计审查补修。最终收据修复的定向集 232 项通过，独立复核另有 20 个场景及 81 项测试；这些不计真实报告语义通过。

## 验证边界

四组以固定官方来源执行 Collector 及下游阶段，依次为 Bitwarden、1Password、Dropbox、Cloudflare，每组两道已审核题。每组最多 24 次模型调用、80000 token，单次输出 2048 token，模型不重试；代码、资料清单、运行与指标脚本先冻结。参考答案和标签不进入 Agent 输入。

这是已曝光开发题的回归，不是盲测或受控 A/B；固定来源阶段流程不代表 Planner 自动发现、完整 Graph 或生产稠密 RAG 验收。正文、保存的回答记录、额外发表主张和系统 QA 分别核对，任务结束不等于报告可交付。

## 尚未解决的原因与下一步

1. **Bitwarden 的事实到回答仍有遗漏**：离职题有两项已识别核心事实被预算省略；离职主张未通过审核、未发表。覆盖提案虽选齐四项澄清字段，但采用 `unknown`，合同要求 `depends`；即使只改此字段，仍缺非空合格事实，不能据此宣称修好。下一步先细化证据发送单元，完整保留规则及例外，再区分事实发布、基于题设的结论与不含产品断言的澄清。
2. **复合主张仍可漏过模型检查**：1Password 一条邀请陈述含两个谓词，operation 绑定只覆盖前半句；后半句在父事实中出现不能补作该引用。下一步收紧支持审核实际可看的绑定片段，要求每个断言明确绑定或拆开；模型自报 `atomicity=supported` 不足以保证原子性。
3. **Reflector 仍有范围误判**：逐题包统一并未保证模型理解交付范围。具体缺价答复与用户尚未提供的输入，应和需要联网补证的缺口分别表达，避免再要求材料补足本可合理拒答的问题。
4. **两套 Writer 派送记录不一致**：共享包事件记录 `unverified`，后续旧交付事件对同一实际成功 span 记录 `dispatch_succeeded`；原始输入可以独立核实原文送达。这是待修的遥测时序，不能据前一事件断言没有发送，也不能将共享包元数据直接计作送达成功。
5. **Dropbox 仍无可准入正文**：两次独立 Fetch 失败，最终只有导航壳，后续生成被阻断。需要针对正文恢复做抓取验证。

真实三组检索记录均为 `degraded_lexical`，没有实际 embedding／reranker 版本；共享入口并未完成生产稠密检索验收。继续优化应先以闭合条件的证据片段和逐题回答合同为单位验证，随后测实际本机语义检索，暂不训练模型。

本轮 `reward=null`、`training_ready=false`；新报告尚未经用户验收。密钥字面量和常见密钥模式扫描覆盖当前非忽略文本、构建及新产物，未检出当前凭据泄漏；没有扫描或宣称扫描完整 Git 历史。
