# 结构化报价证据链交付

日期：2026-10-06。基线：`13612d1`。分支：`codex/pastoral-desktop`。

## 本轮改动

1. 保留 `price` 展示字符串，新增逐报价 `qualifiers` 与 `market`；金额、币种、套餐、席位、税费等条件可进入证据快照，复用现有 Writer/QA 回答边界。
2. 两条价格抽取路径按同一正文行绑定条件。按月标价与按年计费分别记录为 `amount_period` 和 `billing_interval`，不换算总额。Full、Dev、Collab 席位可分别记录；否定、混杂、跨行或未知条件保持缺失。
3. 所有 `price_rows` 准入时重新核对原文与结构字段，不能通过更换抽取器名称绕过。防止抽取结果自行添加金额、币种、席位、市场、验证日期等字段，以及把 `USD2` 当作原文 `USD20` 的金额。报价归一化按自己的 EvidenceItem 保存来源、产品、置信度和原文；相同金额不同条件不会合并，其他来源的旧格式报价也保留。
4. 成功的实际 HTTP/浏览器正文抓取从生产端记录 typed `full_source`，不会信任任意页面元数据提供的来源标记。失败和摘要不能升级正文级别。
5. 官方当前价需通过最终 URL 归属、定价/购买路径、原文验证、来源日期、历史上下文和采集时效检查。任意非空 candidate/typed 来源日期（含非 ISO 或无法解析的日期）均保守阻止当前价升级。`verification_event_at` 记录本次核对事件；`verified_at` 锚定原始 capture，重新入库不能刷新报价新鲜度。
6. 同一来源多市场或包含未知市场时，来源市场保持未知；不使用研究请求的地区填补。通用产品抽取继续限制为最多 8 条报价，避免同价多行无限增长。

现有 answer guard、snapshot、冻结评测、lexical/query intent 和生产 embedding 未修改。本轮模型调用为 0，不计算渠道平均最低价或完整账单费用。

## 离线验收范围

固定虚构产品正文替代 HTTP 请求边界，后续使用实际代码：`EvidenceFetchResult → research pipeline → admission → normalization → RawSource → 临时 RunJournal 保存/重载 → snapshot → Writer evidence context → final QA`。

完整设备和订阅报价能够得到 `answer`。反例包含缺币种/席位/税费/市场、年付月付混杂、跨行条件、不同最终主机、发布日期、首发价、未来及旧缓存、伪造字段、否定席位、多市场、数值区间、复合税费、异常周期类型，以及显式席位标签与自然语言席位冲突。测试先绑定最终报告的 Writer producer，再验证 QA 实际消费的 fact ID，防止提前退出形成假阳性。

## 兼容与限制

旧 `price` 字符串、旧报告和旧字段结构继续可读。新增的 typed capture 来源字段默认为 unknown；历史 capture 若只有页面 metadata 声称 full_source，重放时不会自动获得可信正文资格，需要重新采集。已有 RawSource 存储不作批量迁移。

首版解析常见明确币种代码与单行字段/措辞；含 `not/no/without/unless/excluding/or/或`、标注字段内的并列选项、混合席位/税费，或数值区间（含 `to/到/至`）的单价行保守保留 legacy，并清空结构条件与旧格式套餐/周期，避免误选及 fallback 补回。显式席位标签与自然语言席位不一致时，席位保持缺失。该规则也会降低部分本来合法条件句及复合品牌名称的结构化覆盖率。

复杂表格、动态年付开关、跨行共享上下文、多报价绑定及未识别格式仍保留文本或暴露缺口。这是结构化链路的离线验收，未验收真实网站覆盖率、真实模型生成、Qdrant HTTP 服务，也不能据此宣称 RAG 已合格。
