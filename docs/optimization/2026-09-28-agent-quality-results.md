# 产品竞品研究与 Agent 证据质量：实施结果

日期：2026-09-28。分支：`codex/product-research-generalization`。

## 研究流程

- 新运行由目标产品名称、可选官网、品类、受众、使用场景和市场驱动。竞品发现使用产品名、品类、任务三组查询；只把与候选自身匹配的搜索结果作为发现证据。URL 的查询参数和路径不能单独证明候选身份。
- 发现名单只包含竞争产品。Planner 随后把目标产品作为独立研究对象加入采集、分析、比较矩阵和报告上下文；矩阵把目标标为 `target`，前端显示“目标产品”。没有匹配来源的模型建议不能自动进入采集。
- 指定产品画像时，功能、价格、用户场景从页面原文抽取；缺口与修复查询按通用品类处理。旧的无产品画像运行继续使用原有 AI 功能槽。

## 准确性与时效

- 价格逐条要求同一价格句中出现当前产品名称，保存每一条价格的来源引文。未确定归属的数字不进入当前产品价格，证据准入再次核对价格、产品身份和原文。
- SaaS 价格保留方案名与月付周期；实物商品保留一次性购买。明确否定的功能不记为已支持。
- 历史文章的发布时间、页面更新时间和原始抓取时间在 KB 复用时保留。QA 优先采用明确的事实核验时间，其次采用原文日期；KB 的重复见到时间不能把旧价格“洗新”。企业 KB 同步的 freshness score 也以事实日期计算。
- HTTP 页面质量检查识别登录、验证码、软 404、导航空壳。WebFetch 子进程有总时限、取消清理和可追溯诊断；静态和浏览器抓取通过受控代理连接已校验的公网 IP，浏览器不绕过本地地址代理。PDF 可抽取文本；纯扫描件仍需 OCR。

## 离线验收范围

- `eval/product-discovery-eval.jsonl`：5 个固定样本，覆盖软件、消费应用、电商、硬件和 AI 产品。
- `eval/product-evidence-eval.jsonl`：11 个固定样本，覆盖抓取壳页、动态页空壳、扫描 PDF、事实时效、多品类字段抽取和冲突价格。
- 单元回归另覆盖跨品牌价格误归属、含“分别”的歧义价格、连续价目、逐价格引文、竞品人群归属、KB 旧价格、目标产品进入矩阵、第三方 URL 不升格官网、发现 URL 查询参数误判、WebFetch 私网拦截与 DNS 绑定。
- `webfetch_v2` 的静态模式已实际抓取 `https://example.com`，返回 HTTP 200、页面标题和正文。此检查验证了受控代理的 HTTPS CONNECT 抓取路径；真实 Chromium 浏览器未安装。
- 最终回归：后端 `1489 passed, 1 skipped`；前端 `129 passed`，TypeScript 与 Vite 构建通过；WebFetch 安全测试 `7 passed`；Ruff、密钥扫描、OpenAPI 类型同步和交互审计通过。交互审计有 86 条已有的允许列表告警、0 项错误。最小运行与 Temporal 薄壳烟测通过。

## 运行条件与限制

- 这些样本是离线合成案例，不代表线上搜索召回率。真实竞品发现需要可用的搜索服务密钥，真实网页的质量会受 robots、访问限制和页面结构影响。
- 浏览器抓取依赖可选的 Playwright/Chromium；没有依赖时会返回明确的降级状态。受控代理在实际连接时固定已校验的 IP；部署环境仍应设置独立的网络出口限制。此环境未安装 Chromium，因此浏览器代理路径仅通过离线协议与参数测试，尚未做真实浏览器联网验收。
- 通用抽取采用保守规则：页面未明确写出产品身份或事实时，宁可显示待核验。长篇比较文章中的复杂多产品、多价格排版需要更多真实样本检验。
- 通用人群字段目前优先识别中文“面向／适合／用于”等明确表述；英语网页或只用代词指代产品的段落可能漏抽，需在真实数据评测后扩展。
- 《星露谷物语》风格的像素视觉属于下一阶段，本轮保持现有可操作桌面，把产品研究和 Agent 证据链优先完成。
