用户已批准上一轮方案及本次实施，默认用途为内部产品调研；正式批准/发布仍使用严格门禁。适用于通用产品，不能预设 API 或 AI 品类。

## 已确认要求

1. 使用 DeepSeek V4.1 Flash，官方 API ID `deepseek-flash`，OpenAI 兼容地址 `https://api.deepseek.com`。密钥仅存于被 Git 忽略、权限为 0600 的本地 `.env`。供应商失败不能用 Demo 内容冒充模型结果。
2. 门禁区分事实完整性、关键事实可靠性、分析充分度。内部 quick 不因缺 SWOT 或篇幅被挡；事实引用越界/缺失仍指出问题。正式发布维持严格审查。保留研究深度、运行模式和报告范围。
3. 重做复用既有 line/section/assemble/full 路径，记录问题、修复范围、验收规则、前后版本与改善结果。修复查询按产品品类生成；重复无改善停止。人工修改重新计算事实/引用/QA。
4. Token 记录输入、输出、缓存命中与费用估算，明确估算依据；请求前预留输入/输出预算，并发、重试及恢复不能绕过。稳定提示前缀与精简证据沿用现有 EvidencePack。
5. 历史报告只检索少量相关事实及原始出处，隔离 workspace；价格、版本等过期事实必须再核验；旧判断只作为背景，不计为新独立证据。展示复用/待核验原因。
6. 为后续 Agent RL 提供脱敏轨迹和可复现评测样例，分开训练/验证/留出；当前不运行大规模训练，也不将 Demo 分数作为真实性奖励。
