# RAG 第一阶段验收记录

日期：2026-10-03。实施基线：`0e505b5`；分支：`codex/pastoral-desktop`。

状态：第一阶段实现和离线验收完成，全部规格、质量与最终集成复核通过；最新服务已完成本地只读冒烟检查。改动保存为本地提交，不推送远端。HTTP Qdrant、语义质量及完整联网报告仍未验收。

## 已核验的改动

- 资料和检索使用 typed 工作区 / 项目、完整型号、市场、资料角色与来源时间；SQLite 和 Qdrant 在 LIMIT / top_k 之前过滤。
- 检索缓存包含范围与索引契约；命中回读当前文档，检查版本、hash、活动状态和当前索引。降级与无答案不留成永久缓存。
- 采集时持有的完整正文入库；RawSource 和工具轨迹保留片段及文档引用。并发摘要不能归档或覆盖已保存的全文。
- 知识接口与后台任务由服务端决定范围；企业知识同步限定目标项目和同工作区公共库的原始来源。无工作区 owner 通过旧企业同步入口访问其他工作区的旁路已经修复，并通过独立规格复审。
- 资料引用携带真实项目上下文；详情、分块、版本、删除、回滚与上传轮询沿用相同范围。显式公共库、项目资料、未知归属分别处理；迟到请求不写入新项目页面，混合写范围不合并为默认回滚。

## 审查中修复的行为问题

1. 公共库读取选项曾可能扩大写范围；写入口现在使用精确项目范围。
2. 缓存索引身份不完整、降级后不恢复、市场空值混同等问题已补回归。
3. 伪造 KB 标记可以抑制摘要更新，并发摘要可能归档全文；已通过可信检索标记和事务内全文保护修复。
4. 后台抓取入库曾把旧页面核验时间写成本次入库时间；改为原始页面抓取时间。
5. 企业 KB 同步四个入口沿用旧权限 helper，导致未绑定工作区的 owner 可同步其他工作区资料；改为严格 scope 校验，任务详情同时检查保存的工作区 / 项目。
6. 来源删除后，已开始的抓取仍可能首次发布正文、覆盖取消状态或添加新子任务；现在在对应 SQLite 写事务中检查来源与取消状态。正值预算配置为零导致 running 卡住的回归也已修复。
7. 历史价格曾因当日成功抓取被判为当前事实；抓取核验与日期敏感事实的原时间现在分别保留，迁移 14 追加 typed 来源更新时间，避免仅有更新日期的旧价格回退到当前抓取时间。
8. 通用 metadata 可覆盖候选出版日期，KB generic 日期还曾填补 typed 空值；出版与更新时间现在通过明确的候选 / 抓取结果字段传递，准入对两者均执行覆盖保护。旧报告链接重新抓取的原日期断言保留。
9. 归属缺失引用曾被误当成公共库，QA compact 还会丢弃公共库的显式 null；引用保留三态，企业回滚按引用范围处理，不继承知识页面残留范围。
10. 摘要与完整正文恰好同 hash 时，快速去重曾保留 summary 等级，使后续摘要还能归档全文。现在在事务内单调提升全文等级，原来源时间、版本、正文、已有分块及索引不变；两个连接的竞争也受保护。
11. 旧进程可在已迁移的库上重建两条全库唯一索引，并在去重时归档其他范围的资料。初始化现在在去重前清理这两条遗留索引，即使迁移版本已应用也会执行；范围内唯一约束继续保留。根据更新前备份恢复一条受影响资料的活动标志，其余原字段未改动。

## 本阶段不能宣称已完成的能力

- Qdrant 本地测试使用真实持久化客户端，证明写入、过滤、重开读取和删除；运行中的 HTTP Qdrant 服务尚未验收，本地测试不是运行环境部署。
- 当前离线 embedding / reranker 仍是 hash provider，Collector 使用关键词检索；尚未证明中文语义召回和重排质量。
- 还没有所有 Agent 共享的证据快照、统一冲突决策和各阶段的检索预算。
- 没有重新调用付费服务生成完整联网报告；此前真实报告失败后的离线修复不能代替完整实跑验收。
- 旧资料和旧任务保持原数据，未知归属不会自动共享；缺少可信归属的旧引用可能无法回查。归属确认、补索引与迁移工具属于后续工作。
- 重复正文保留原文档来源时间；真实重复核验事件及向量时间更新尚待设计，不把同步、重排和重复入库视为新核验。
