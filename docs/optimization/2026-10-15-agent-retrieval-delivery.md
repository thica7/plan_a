# Agent 检索接线与离线回归交付

## 本轮范围

按用户确认，将查询规划与稀疏召回优化接入实际 Agent 检索入口，并更新中文 README、Agent 执行说明及本阶段代码。没有提高工作区额度或调用外部模型。

执行计划见 [实施计划](2026-10-15-agent-retrieval-delivery-plan.md)，Agent 输入输出、入口和限制见 [执行说明](../agent-execution.md)。

## 实际修复

1. **查询规划 `intent-v3`**：保留原始问题，区分格式与事实查询；按识别到的主题、产品、维度生成最多 5 条查询。数值保留原始字面，避免自动规划把 `50.5Wh` 拆成其他数值。未知中文及未覆盖子句留在诊断中待核对，不能把检索到主题资料当成命题已被证实。
2. **词法策略 `lexical-v3`**：增加有限中英概念匹配与问句语法清理；保留有界 fallback，未使用无约束全词 OR。SQLite 分词存储未变，查询及词法版本进入响应缓存身份。
3. **标题与正文联合召回**：产品/型号在标题、主题在正文时，要求二者属于同一 canonical 文档。不能用同范围的其他文档标题替代，工作区、项目、来源角色与版本校验仍执行。
4. **单位写法**：有限兼容 `Wh` / `Whr` 和单位前空格，保留数值与量纲。小数、符号、数字后缀及分数反例防止 `.5Wh` 被当成 `5Wh`、`50Wh` 被当成 `50W` 或 `500Wh`；未支持的格式保守处理。
5. **Collector 分支接线**：按当前产品和维度规划，避免把计划内其他竞品名称或 skill 描述作为必选查询词；完整原始调研要求保留在跟踪与来源元数据中。
6. **下游共享消费**：取证通过准入后进入快照，供 Analyst、Comparator、Reflector、Writer、QA 消费。写作与审核不绕过准入自行替换引用。

全量回归还发现并修复了目标产品未列入 `competitors` 时的查询污染。长中文研究目标在缺少具体检索主题时，只有满足单产品、单维度、明确作用域、来源角色及无额外数值条件，才可走显式记录的 `dimension_scope_lookup`；它是在精确元数据过滤下按产品名做 FTS 范围查找，不能称作事实问题解析。短查询和英文关键词保留原路径。

## 固定原样本的本机模型比较

22 条固定来源、8 道已人审题：6 道答案题、1 道资料不足题、1 道需澄清题。语料、原问句与标签字节未修改；模型为本机 E5-small 与可选 BGE cross-encoder，网络访问被拦截。

| 查询路径 | 联合候选覆盖（6 答案题） | 最终 top-3 | 原文证据节选覆盖 |
| --- | --- | --- | --- |
| raw + sparse | 0/6 | 0/6 | 0/6 |
| raw + hybrid | 6/6 | 6/6 | 6/6 |
| raw + hybrid + BGE | 6/6 | 6/6 | 6/6 |
| structured + sparse | 5/6 | 5/6 | 5/6 |
| structured + hybrid | 6/6 | 6/6 | 6/6 |
| structured + hybrid + BGE | 6/6 | 6/6 | 6/6 |

同一排名的 top-1 结果也分别为 0/6、6/6、6/6、5/6、6/6、6/6。本轮外部模型调用 **0**，网络尝试 **0**。第一次 `lexical-v2` 的 structured sparse 为 3/6；标题/正文和单位修复后为 5/6，两个中间结果分开保留。

### 怎样理解这些数字

- **剩余失败**：005 未在问题里给出明确产品实体，自动规划保守回退，长句稀疏匹配仍失败。没有为 GitHub 或评测编号编写例外。实际 Collector 有明确产品范围，另有多产品分支测试；不能把该测试冒充此独立问题已通过。
- **raw 对照**：保留原始查询、不做自动事实规划，但共享当前词法策略。旧 `lexical-v1` 的 0/6 是历史记录，当前脚本没有冻结旧引擎实现。
- **候选池**：每子查询/每模态取 20 条，先验证范围与 canonical，再记录联合池；hybrid 最多 5×2×20 条 chunk，精排最多 20 条，再取 top-3。本集每题仅 13 条合格资料，hybrid 候选池已覆盖全体，不能据此宣称大库召回优秀。
- **精排增益**：本小集 top-1/top-3 未表现出额外收益，不能声称精排提高准确率。
- **非盲测**：这 8 题已经曝光。新增合成边界用例属于工程回归，未经独立人审，未混入正式标签。`semantic_quality_verified=false` 保持不变。
- **回答控制未验收**：本比较执行检索；资料不足和澄清题没有生成答案评分。RAGAS、独立生成式事实准确率与完整报告质量不在本次结果中。

## 当前仍未完成的验收

- 四产品新真实流程被工作区月度 token 配额返回 429，尚未创建新 run；本轮未提高额度、未重跑付费流程。既有报告仍是其原运行版本，不能视为新代码的质量验收。
- 未解析子句、复杂语义条件与格式指令仍可能混杂，例如“请保留电池口径”中的“保留”可能被识别成 retention 主题；原始子句保留供后续核对，尚未全面解决。
- HTTP Qdrant、Temporal、Redis 多 worker 和实机 Postgres RLS 仍需独立部署验收。本轮使用本机持久化 Qdrant，不代表生产集群已通过。

下一步优先扩充未曝光、按产品与复杂条件分层的人审集；分别评测候选覆盖、最终排名、回答主张与引用。额度允许后，再用最终代码重跑四产品报告，检查操作覆盖、角色/套餐/访问前提和已采证据进入正文的比例。
